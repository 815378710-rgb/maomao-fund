# 🐱 猫猫基金宝

实时基金估值工具，支持图片识别导入、多源数据、分时走势、多账户持仓管理。

## ✨ 功能特性

### 核心功能
- 📊 **实时估值监控** — 多基金同时追踪，自动刷新
- 📈 **分时走势图** — 今日估值变化一目了然
- 💼 **多账户持仓管理** — 支持多个账户独立管理持仓
- ⭐ **自选基金** — 快速添加关注的基金
- 📈 **资金流入榜** — 查看热门基金排行

### 🆕 v3.0 新增功能
- 📷 **图片识别导入** — 上传持仓截图，AI自动识别基金代码、份额、成本
- 🏷️ **关联板块** — 每只基金显示所属行业板块（半导体/新能源/医药等）
- 👁 **隐私模式** — 点击眼睛图标一键隐藏所有金额
- 🏦 **多账户支持** — 创建不同账户分别管理持仓
- 🔖 **持仓标记** — 已持有的基金在搜索和自选中自动标记

### 数据保障
- 🔄 **多源数据** — 天天基金 → 金融界，自动降级
- ✅ **估值校验** — 净值与涨跌幅交叉验证
- ⏰ **时效检测** — 实时显示数据新鲜度
- 🔒 **精度保障** — 统一4位小数，异常数据标记提醒

### 增强功能
- 📋 **基金详情** — 基金经理、规模、费率、排名、最大回撤、夏普比率
- 📊 **历史业绩** — 近1月/3月/6月/1年收益率
- 🏢 **前十大持仓** — 展示基金重仓股及占比
- 📤 **数据导出/导入** — JSON格式备份恢复
- 🌙 **暗色/亮色主题** — 一键切换
- 📱 **PWA 支持** — 可添加到手机桌面
- 🔍 **增强搜索** — 基金类型筛选、最近搜索记录、持仓标记

## 🚀 使用方式

直接在浏览器打开 `index.html` 即可使用。

### 图片识别功能
1. 进入「我的持仓」页面
2. 点击「📷 图片识别导入」
3. 在设置中配置 MiMo API Key
4. 上传持仓截图，AI 自动识别基金信息
5. 勾选要导入的基金，点击「导入选中」

## 📦 技术栈

- 纯前端 HTML/CSS/JS，无需后端
- ECharts 5.4 图表库
- MiMo v2.5 多模态AI（图片识别）
- 天天基金/金融界 API
- localStorage 本地存储
- PWA Service Worker
