# 🐱 猫猫基金宝

实时基金估值工具，支持多源数据、分时走势、持仓管理。

## ✨ 功能特性

### 核心功能
- 📊 **实时估值监控** — 多基金同时追踪，自动刷新
- 📈 **分时走势图** — 今日估值变化一目了然
- 💼 **持仓管理** — 添加/编辑/删除持仓，自动计算盈亏
- ⭐ **自选基金** — 快速添加关注的基金

### 数据保障（v2.0 重点修复）
- 🔄 **多源数据** — 天天基金 → 金融界 → 好买基金，自动降级
- ✅ **估值校验** — 净值与涨跌幅交叉验证，异常数据标记提醒
- ⏰ **时效检测** — 实时显示数据新鲜度，过期数据明确提示
- 🔒 **精度保障** — 统一4位小数显示，涨跌幅与净值自动校准

### 增强功能
- 📋 **基金详情** — 基金经理、规模、费率、排名、最大回撤、夏普比率
- 📊 **历史业绩** — 近1月/3月/6月/1年收益率
- 🏢 **前十大持仓** — 展示基金重仓股及占比
- 📤 **数据导出/导入** — JSON格式备份恢复
- 🌙 **暗色/亮色主题** — 一键切换
- 📱 **PWA 支持** — 可添加到手机桌面
- 🔍 **增强搜索** — 基金类型筛选、最近搜索记录

### 智能刷新
- 交易时段：20秒刷新
- 非交易时段：5分钟刷新（节省流量）
- 周末/节假日：自动暂停

## 📦 技术栈

- 纯前端 HTML/CSS/JS，无需后端
- ECharts 5.4 图表库
- 天天基金/金融界/好买基金 API
- localStorage 本地存储
- PWA Service Worker

## 🚀 使用方式

直接在浏览器打开 `index.html` 即可使用。
